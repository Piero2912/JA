🎯 QUÉ SE IMPLEMENTÓ

✅ 3 JUEGOS TOTALMENTE FUNCIONALES:
   • Juego 1: Imagen que se Aclara
     - Cargar imágenes
     - Definir elementos y puntos
     - Progresión visual de claridad
     - Adivinar imagen completa
   
   • Juego 2: Completa el Versículo
     - Crear versículos con palabras en [corchetes]
     - Ocultación automática por nivel (Niños/Jóvenes/Adultos)
     - 3 ejemplos incluidos
     - Selección de palabras y asignación de puntos
   
   • Juego 3: Ordena la Historia con Cronómetro
     - Crear historias con 5 hechos
     - Cronómetro independiente por bando
     - Penalizaciones por orden incorrecto
     - Tiempo límite configurable

✅ CARACTERÍSTICAS GENERALES:
   • Menú principal intuitivo
   • Configuración de bandos (nombres y colores)
   • Marcadores independientes por juego
   • Almacenamiento automático en localStorage
   • Exportación/Importación de respaldos JSON
   • Modo presentación (oculta controles del animador)
   • Pantalla completa
   • Atajos de teclado
   • Sonidos Web Audio (acierto, error, victoria)
   • Animaciones suaves y confeti
   • Interfaz 100% responsive para TV 16:9

🚀 CÓMO INICIAR (3 PASOS SIMPLES)

1. ABRIR LA APLICACIÓN
   → Navega a la carpeta del proyecto
   → Abre "index.html" con tu navegador (cualquiera: Chrome, Firefox, Edge, Safari)
   → Aparecerá el menú principal
   → ¡LISTO! No requiere instalación adicional

2. CONFIGURAR BANDOS (primera vez)
   → Haz clic en "⚙️ Configurar Bandos"
   → Edita nombres y colores
   → Guarda

3. CREAR CONTENIDO Y JUGAR
   → Elige uno de los 3 juegos
   → Crea rondas, versículos o historias
   → Juega
   → Los datos se guardan automáticamente

⌨️ ATAJOS PRINCIPALES

Ctrl+P  ← Alternar Modo Presentación (oculta tus controles)
F11     ← Pantalla Completa
M       ← Mostrar ayuda de atajos
ESC     ← Volver al menú
1       ← Asignar punto a Bando Izquierdo
2       ← Asignar punto a Bando Derecho
0       ← Nadie acertó (Juego 2)

💾 ALMACENAMIENTO DE DATOS

• Ubicación: localStorage del navegador (5-10 MB disponibles)
• Automático: Se guarda cada vez que haces cambios
• Persistente: No se pierden al cerrar el navegador
• Respaldos: Exporta a JSON desde el menú (botón 📥)

IMPORTANTE: Si limpias el caché del navegador, los datos se pierden.
SOLUCIÓN: Haz un respaldo JSON antes de limpiar caché.

🎮 JUEGO POR JUEGO - CÓMO FUNCIONA

JUEGO 1: IMAGEN QUE SE ACLARA
├─ Creas una ronda con una imagen
├─ Escribes la respuesta (ej: "El arca de Noé")
├─ Añades elementos (ej: "animales", "paloma", "lluvia")
├─ Durante el juego, la imagen está muy borrosa
├─ Cada elemento que adivinan → imagen se aclara un paso
├─ Pueden intentar adivinar la imagen completa
└─ Gana quien adivine primero O tenga más puntos

JUEGO 2: COMPLETA EL VERSÍCULO
├─ Creas un versículo con palabras en [corchetes]
├─ O usas "Generar automáticamente" por nivel
├─ Durante el juego, ves espacios en blanco
├─ Seleccionas el espacio y asignas quien lo acertó (1/2/0)
├─ Cada palabra suma puntos
├─ Varias versículos seguidos
└─ Gana quien tenga más puntos al cerrar

JUEGO 3: ORDENA LA HISTORIA CON CRONÓMETRO
├─ Creas una historia con 5 hechos en orden correcto
├─ La app los mezcla (igual para ambos bandos)
├─ Cuenta regresiva 3-2-1, cronómetro comienza
├─ Arrastra o usa botones para reordenar
├─ Presionan "¡Listo!" para validar
├─ Si está mal: muestra error, suma penalización, continúa
├─ Si está bien: detiene su tiempo
└─ Gana quien complete primero (o en menos tiempo si ambos aciertan)

🆘 SOLUCIÓN DE PROBLEMAS COMUNES

"La app no carga"
→ Verifica que todos los archivos .js estén en la carpeta js/
→ Intenta en otro navegador

"Se perdieron mis datos"
→ Restaura desde tu respaldo JSON (si lo exportaste)
→ Si no tienes respaldo: no se pueden recuperar
→ ACCIÓN: Ahora mismo, haz un respaldo (📥 Exportar)

"Los sonidos no se escuchan"
→ Verifica que tu navegador tenga audio habilitado
→ Presiona el botón 🔊 (no está silenciado)
→ Sube el volumen de tu computadora

"La pantalla está pequeña en el TV"
→ Presiona F11 para pantalla completa
→ Aumenta los tamaños en styles.css si es necesario

"Los botones no responden"
→ Abre la consola (F12)
→ Busca errores en rojo
→ Revisa el archivo mencionado en el error

👨‍💻 PARA MODIFICAR EL CÓDIGO (Estudiantes de Sistemas)

El código está completamente modular y comentado:

• Agregar un nuevo juego: Copia game1.js, modifica la lógica
• Cambiar colores: Edita :root en styles.css
• Cambiar sonidos: Modifica audioSystem en audio.js
• Cambiar textos: Edita las plantillas HTML en app.js
• Aumentar límites: Edita las constantes de los games

Cada archivo tiene comentarios explicativos para que entiendas la estructura.
